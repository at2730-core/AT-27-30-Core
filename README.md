# AT-27-30-Core

Nueva arquitectura de datos para la evolución de AT 27-30 hacia una Plataforma de Inteligencia Territorial y Copilot Electoral (HEYTI).

## Objetivo

Construir una infraestructura moderna basada en PostgreSQL/PostGIS para soportar:

* Análisis Territorial
* Ganar Todo
* Operaciones de Campo
* Estructura Territorial
* Día D
* Indicadores Estratégicos
* Recomendaciones HEYTI

## Tecnologías objetivo

* PostgreSQL
* PostGIS
* Docker
* Python ETL
* Git
* VS Code
