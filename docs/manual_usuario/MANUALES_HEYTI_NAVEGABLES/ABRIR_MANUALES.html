Cómo leerlos

  1. Abre el documento que necesites y pulsa una sección de su índice.
  2. Usa A+ para ampliar la letra y Alto contraste si te facilita la lectura.
  3. Para encontrar una palabra, pulsa Ctrl + F.
  4. Para una copia imprimible, pulsa Imprimir / PDF y selecciona la impresora o la opción de guardar como PDF del navegador.

Los cinco documentos funcionan sin Internet. Las notas para Alex son observaciones de documentación y no sustituyen los manuales de uso.

Si compartes todos los documentos, conserva esta carpeta completa. Cada manual también contiene su texto, formato y controles dentro de su propio archivo HTML.
